## 下载与运行

下载 `AutoTestHost-v0.1.0-windows-x64.zip`，解压后运行 `AutoTestHost.exe`。EXE 无需 Python，仍需本机仪器驱动和适用的 VISA 后端。完整源码安装、接线、测试和打包方法见仓库 README。

`SHA256.txt` 校验单独 EXE，`SHA256SUMS.txt` 同时校验 EXE 和发行 ZIP。全量本机报告、虚拟环境、构建缓存与凭据不包含在源码和发行包中。
