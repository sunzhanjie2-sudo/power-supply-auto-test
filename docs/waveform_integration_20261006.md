# 波形模块集成交付验证

已将 ScopeHost 0.3.0 的波形模型、归档、统计、PNG 渲染和波形控件集成到自动化测试程序。来源为 `E:/CODE/scope/scopeapp`，原项目源码未修改；来源校验值见 `auto_test/waveforms/ORIGIN.json`。当前 EXE 已包含模块，运行不依赖另一个项目目录。

## 使用方式

- 实时波形采用 ScopeHost 风格网格、通道颜色、量程和时基显示，复用自动测试程序的示波器连接。
- 用例测试中选择已完成工况，点击“查看工况波形”或双击该行，打开离线查看窗口。
- 支持时间缩放和平移、ZOOM 局部放大、A/B 游标、电压放大、参考波形和 FFT。显示操作不修改采样或仪器设置。
- “打开历史波形”可读取 NPZ 或带 Time_s 的旧 CSV；旧 CSV 缺失的设置仅用于按数据范围显示，不作为新增实测证据。
- 每个工况保存同名 PNG、CSV、NPZ、JSON；报告执行汇总提供三种文件的链接。NPZ 可在原 ScopeHost 的“打开波形归档”中加载。

## 数据与控制

采样、原始 ADC 码、量程、偏移、耦合、触发和时间轴设置在同一次停止采集中读取，随后才恢复采集。CSV、NPZ 与报告图片使用该记录。动态/启动电压和纹波 Vpp 按保存的采样计算；纹波工况另有 DC 稳压测量，其 AC 波形不表示直流输出电压。

PNG 渲染按每个像素保留最小/最大采样值，避免窄尖峰被插值或抽点遗漏。DS1152E 当前为 600 点屏幕记录；时间轴及 FFT 使用传输记录的有效点间隔，图中的采样率不是仪器最高 ADC 采样率。稳态记录保留原驱动的 VAV 校正，原始 ADC 码和 dc_anchor_shift 同时归档。

负载联调发现过 INP ON 后持续回读 OFF、保护寄存器为 0 的情况。现在负载查询和设置之间有处理间隔；输入操作先等待状态回读，再有限重试，已报告保护时停止开启重试。未确认状态保持 ERROR，并记录响应与保护状态。测试判据没有放宽。
